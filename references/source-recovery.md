# 原作品找回：不是找一个“差不多”的视频

## 自动化多渠道检索工具（优先使用）

技能内置了多渠道自动检索、截断自愈与严格反冒充核验引擎：

```powershell
$py = 'E:\app\Miniconda\python.exe'
$cli = 'D:\AI-Skills\skills\video-doc-weekly-orchestrator\scripts\weekly.py'

# 1. 扫描截图 OCR 自动识链自愈（解决屏幕上有链接却遗漏的问题）
& $py -B $cli auto-heal --run '<工作目录>'

# 2. 导出未决条目的 ChatGPT 深度反查提示词清单
& $py -B $cli chatgpt-sheet --run '<工作目录>'

# 3. 运行多渠道检索（B站API直搜 + 导入ChatGPT检索结果）
& $py -B $cli search-missing --run '<工作目录>' [--chatgpt-results '.\chatgpt-found.json']

# 4. 针对实在找不到的无外链条目，抽取原录像对应时间戳的高清截图
& $py -B $cli capture-screenshots --run '<工作目录>'
```

## 证据两层原则（不可混淆）

1. **可访问性**：当前链接有作品详情/有效元数据，不是登录墙、广告页、失效壳。
2. **同一作品**：来源条目与详情标题/作者/画面一致，或有可解释的原文简写/标题变更证据。

二者完全独立。健康的 BVID、完整的 19 位数字、搜索高排名、同作者同题材都不自动满足第二层。`same_work/title_match` 必须经过真实核对，严禁使用低置信度相似度或批量假值冒充。

## 找回顺序（逐条、分层，保留每次证据）

### A. 邻帧回捞（原录像时间戳）
回到原录像该项所属时间点，查看前后 2–5 秒（或在脚本中调用 `scan_neighboring_video_frames`）；观察正文下方或右侧是否有完整的 19 位抖音 ID 或 BVID。很多视频在播放或滑动时会显示完整链接。

### B. 截断 ID 补全
提取截断的 11-18 位纯数字，在站内或搜索引擎搜索该前缀，配合标题核实，找回完整 19 位作品 ID。

### C. 右侧 ChatGPT 深度反查
利用 `weekly.py chatgpt-sheet` 导出的提示词，在右侧 ChatGPT 标签页中发送，输入标题、作者线索、正文核心金句。利用大模型联网检索能力秒级定位原始出处，再将返回的链接导出为 JSON 批量核验。

### D. 平台站内精准搜索
- **B 站**：调用 `search_bilibili_web_api` 或在搜索栏输入标题与 UP 主，核对核心关键词匹配度；
- **抖音**：在浏览器标签页打开 `douyin.com/search` 搜索标题与作者；

### E. 搜索引擎（Bing/Baidu）
搜索 `site:bilibili.com/video <标题>` 或 `site:douyin.com/video <标题>`，获取原始索引。

## 严格互斥与截图对照门禁

- **互斥铁律**：凡是通过以上防线找回明确外链的条目，**坚决不放截图**！系统会自动清除其图片占位符；
- **真实无外链条目**：仅对经过所有渠道仍确认无独立外链的条目（口播感悟、内部课宣讲、本地知识库随笔），提取原录像讲解该条目的高清截图；
- **时间戳精准性**：截图截取的时间戳必须严格对应讲解该条目的画面，截图中必须清晰呈现该条目的序号或核心标题（杜绝“标题是25，截图里没有25的内容”）。
